Estructuras de Datos · Listas enlazadas en C++

    
Vi Estructuras de Datos en el periodo 2024-1. En abril de 2025 volví por mi cuenta a repasar listas enlazadas simples y escribí este programa: crea la lista, inserta al final, busca un valor y elimina nodos (al inicio o en medio). A la derecha puedes jugar con la misma lógica: cada botón ejecuta la función equivalente y la resalta en el código.

    
C++PunterosMemoria dinámica (new / delete)2024-1 · Repaso abril 2025

    

      

        
listas_enlazadas.cpp

        
#include<iostream>
using namespace std;

struct Nodo{
    int dato;
    Nodo* sig;
};

void crearLista(Nodo*& cab, int d){
    Nodo* nuevo = new Nodo;
    nuevo->dato = d;
    nuevo->sig = NULL;
    cab = nuevo;
}

void insertarFinal(Nodo* cab, int d){
    Nodo* aux = cab;
    Nodo* nuevo = new Nodo;
    nuevo->dato = d;
    
    while(aux->sig != NULL){
        aux = aux->sig;
    }
    
    aux->sig = nuevo;
    nuevo->sig = NULL;
    
}

void mostrarLista(Nodo* cab){
    Nodo* aux = cab;
    while(aux != NULL){
        cout<<aux->dato<<" -> ";
        aux = aux->sig;
    }
    
}

Nodo* buscarNodo(Nodo*cab, int d){
    Nodo* aux = cab;
    while(aux != NULL){
        if(aux->dato == d){
            return aux;
        }
        
        aux = aux->sig;
    }
    
    return NULL;
}

void eliminarInicio(Nodo*& cab){
    Nodo* aux = cab;
    cab = cab->sig;
    delete aux;
}

void eliminarMedio(Nodo* cab, Nodo* elim){
    Nodo* aux = cab;
    while(aux->sig != elim){
        aux = aux->sig;
    }
    
    aux->sig = elim->sig;
    delete elim;
}

int main(){
    Nodo* cab = NULL; Nodo* buscar = NULL;
    int dato, N;
    
    cout<<"Digite la cantidad de datos que desea: ";
    cin >> N;
    
    for(int i = 1; i <= N; i++){
        cout<<"Digite el dato "<<i<<" : ";
        cin >> dato;
        if(cab == NULL){
            crearLista(cab,dato);
        }else{
            insertarFinal(cab,dato);
        }
    }
    
    mostrarLista(cab);
    int opc = 1;
    while(opc == 1){
        cout<<endl<<"Digite un valor para verificar si existe: ";
        cin >> dato;
        buscar = buscarNodo(cab,dato);
        if(buscar != NULL){
            cout<<"El dato existe";
        }else{
            cout<<"El dato no existe";
        }
        
        cout<<"\nDesea continuar? 1. Si 2. No ";
        cin >> opc;
    }
    
    opc = 1;
    
    while(opc == 1){
        do{
            cout<<endl<<"Digite un valor para eliminar: ";
            cin >> dato;
            buscar = buscarNodo(cab,dato);
            if(buscar != NULL){
                cout<<"El dato existe en la lista";
            }else{
                cout<<"El dato no existe";
            }
        }while(buscar == NULL);
        
        if(buscar == cab){
            eliminarInicio(cab);
        }else{
            eliminarMedio(cab,buscar);
        }
        
        cout<<endl<<"Lista modificada..."<<endl;
        mostrarLista(cab);
        cout<<"\nDesea continuar? 1. Si 2. No ";
        cin >> opc;
    }
    
    cout<<"Mision cumplida :D"<<endl;
    
}

      

      

        
Simulador de la lista

        
Escribe un número y elige una operación. El nodo rosado es la cabeza (cab); el amarillo es aux recorriendo la lista.

        

          
          
          
          
          
        

        

        
salida del programa

      

    

    

      
Punteros y referenciasNodo*& cab permite que la función cambie la cabeza real, no una copia.

      
Recorrido con auxAvanzar nodo por nodo con aux = aux->sig hasta llegar a NULL.

      
Memoria dinámicaCada new reserva un nodo y cada delete lo libera al eliminarlo.

      
Casos especialesEliminar la cabeza no es igual que eliminar en medio: por eso hay dos funciones.

1 · La técnica Feynman

    

      

        
Richard Feynman fue un físico teórico estadounidense, conocido por la formulación de integrales de camino en la mecánica cuántica, la electrodinámica cuántica y la física de la superfluidez del helio líquido. Su lema práctico: si no puedes explicarlo de forma simple, aún no lo entiendes.

        
  1. Elige un concepto.
  2. Explícalo como si fuera para un niño.
  3. Detecta dónde te trabas y vuelve a la fuente.
  4. Simplifica con analogías.
